# Mac

## 1. 安裝

1. 打開人哋send畀你嘅 `.dmg`。
2. 拖 **BNO Tracker** 入 **應用程式（Applications）** 資料夾。
3. 推出個磁碟映像。

## 2. 第一次開

第一次 double-click 係 **開唔到** 嘅。macOS 會擋住冇經過 Apple 簽名同公證
嘅 app，而呢個 app 兩樣都冇。

> **如果見到「BNO Tracker 已損毀，無法打開」** — 咁就唔關下面啲步驟事，
> 做極都冇用。呢個代表你攞到嘅係 0.2.0 版，個簽名整壞咗。同人攞返個新
> 版本就得，0.2.1 或者之後嘅版本冇呢個問題。唔好照佢講咁掉入垃圾桶，
> 換返個新嘅就得。

要咁做：

1. 打開 **系統設定 → 私隱與安全性**。
2. 掕到 **安全性** 嗰部分。
3. 你會見到一行寫住 已阻止「BNO Tracker」，隔籬有粒 **仍要打開**，撳佢。
4. 用 Touch ID 或者密碼確認。

如果搵唔到嗰行，就先 double-click 個 app 一次 — 要 macOS 擋過一次，嗰個
選項先會出現。

之後就同普通 app 一樣，double-click 就開到。

> **每個 macOS 版本嘅字眼同介面都可能唔同。** 呢啲步驟係照 macOS 26 寫嘅。
> 如果你見到嘅唔一樣，記住要搵嘅嘢 一定喺「私隱與安全性」入面，喺安全性
> 嗰段下面，而且要你試過開一次先會出現。

## 3. 點解會有呢個警告

Apple 收 US$99 一年先畀你個開發者簽名。冇買嘅話，任何 app — 無論安唔安全 —
都會彈同一個警告。個警告講嘅係 **邊個簽咗名**，唔係講個 app 做緊乜。

你可以自己查佢有咩權限。全部寫晒喺
[`desktop/src-tauri/capabilities/default.json`](../desktop/src-tauri/capabilities/default.json)：

- 淨係可以喺自己嗰個 Application Support 資料夾入面 讀同寫
- 可以喺瀏覽器開一條連結（畀 gov.uk 官方指引嗰條用）
- 你匯出／匯入嗰陣，可以叫系統嘅「儲存／開啟」對話框

**冇任何網絡權限。** 個 app 一個網絡請求都唔會發 — 完全 offline 都用得，
你可以熄咗 Wi-Fi 自己試。

## 4. 你嘅資料放喺邊

# Windows

下面啲嘢全部都係喺 CI 度用一部乾淨嘅 Windows 機實試過先寫，除咗 SmartScreen
嗰個警告視窗嘅確實字眼 — 見第 2 步嘅註。

## 1. 安裝

1. Double-click **BNO Tracker_x.y.z_x64-setup.exe**。
2. Windows 會先彈個警告出嚟 — 見第 2 步。
3. 安裝 唔需要管理員權限，淨係裝畀你自己一個用戶，裝喺
   `C:\Users\<你>\AppData\Local\BNO Tracker`。
4. 裝完會喺 開始功能表 同 桌面 各整一個叫 *BNO Tracker* 嘅捷徑。

## 2. SmartScreen 嘅警告

個安裝檔 冇買過程式碼簽名證書，呢點已經確認咗：Windows 報告佢嘅簽名狀態
係 `NotSigned`。所以第一次開嗰陣 SmartScreen 一定會擋。呢個係正常嘅，佢針對
嘅係 邊個簽咗名，唔係個程式做緊乜。

一般嚟講會見到一個藍色視窗，寫住 **「Windows 已保護你的電腦」**，而你要撳
嘅掣係收埋喺 **其他資訊** 後面：

1. 撳 **其他資訊**。
2. 撳 **仍要執行**。

> **呢個視窗我自己冇親眼見過。** 個 app 係喺一部冇螢幕嘅機上面 build，所以
> 上面嘅步驟係 SmartScreen 一般嘅流程，唔係針對你部 Windows 驗證過嘅。已經
> 確認嘅係：個安裝檔冇簽名，所以一定會彈警告。如果你見到嘅唔一樣，你要搵
> 嘅就係一個會露出「仍要執行」選項嘅連結或者掣 — 微軟每個版本都搬嚟搬去。

如果你根本唔想撳過任何安全警告（呢個想法好合理），叫 Daniel 幫你裝就得。

## 3. 你嘅資料放喺邊

```
C:\Users\<你>\AppData\Roaming\uk.bnotracker.app\
    bno-tracker.json        ← 你嘅記錄
    backups\
        2026-09-15.json     ← 每日自動留一個，保留最近 30 個
```

喺檔案總管嘅位址列貼 `%APPDATA%\uk.bnotracker.app` 就去到。注意呢個係
**Roaming**，唔係個 app 自己裝落去嗰個 `Local` 資料夾 — 程式同你嘅記錄
係特登分開放嘅。

**記得備份呢個資料夾。** 如果想要一份可以 email 或者放落 USB 嘅副本，用
app 入面嘅 **匯出 JSON**，佢會喺你揀嘅位置寫一個檔案出嚟。

**要復原：** 用 **匯入 JSON**，揀返個匯出檔或者 `backups\` 入面其中一個日期檔。
個 app 會先檢查份檔案先接受，所以揀錯檔或者檔案壞咗都會被拒絕，唔會蓋走
你嘅記錄。

## 4. 想移除

設定 → 應用程式 → 已安裝的應用程式 → **BNO Tracker** → 解除安裝。或者直接行
安裝資料夾入面嘅 `uninstall.exe`。

已經實試過：解除安裝只會移除程式，你嘅記錄會原封不動。第 3 步嗰個資料夾
會留低，所以你之後再裝返，啲嘢仲喺度。連記錄都想刪就自己手動刪嗰個資料夾。
